# Relay

A real-time multiplayer word game. Create a room, share the code, and outlast everyone else.

🚧 **Status: Under development.** Features and structure may change frequently.

## How It Works

1. A player creates a room and shares the room code.
2. Friends join using the code (5+ players).
3. Each turn, a player gets 2-3 starting letters and has about 10 seconds to make a valid word.
4. Fail to answer in time and you're eliminated.
5. The last player standing wins.

## Features

- [x] Player and Room models (join, turn order, elimination)
- [ ] Create/join rooms via code
- [ ] Turn timer (~10 seconds)
- [ ] Real-time gameplay between players
- [ ] Simple, clean frontend
- [ ] Live deployment

## Tech Stack

- Backend: Python, FastAPI, Uvicorn
- Frontend: HTML, CSS, JavaScript
